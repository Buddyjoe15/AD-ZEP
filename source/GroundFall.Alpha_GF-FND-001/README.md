# GroundFall.Alpha — GF-FND-001 Foundation Harness

This checkout is the Platform foundation task around the Human-approved `Groundfall_Master_v0_7_0.html` baseline.

The game source remains a standalone HTML artifact. GF-FND-001 adds reproducible identity, build, test, contract, dependency-boundary, evidence, and isolated-worktree tooling without changing the game bytes.

Start with:

```sh
npm test
npm run build
```

See `docs/DEVELOPMENT_HARNESS.md` and `docs/PLATFORM_FOUNDATION.md` for launch modes, update order, coordinate terminology, ownership, and verification limits.
