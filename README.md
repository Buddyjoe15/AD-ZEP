# Abyssal Dawn: Zero Earth Protocol — v0.7

A browser expedition strategy game. Commander Elias Vance and the UES Aster Vale land on an unfamiliar Earth. You study signals, mine metal with Utility Spiders, fabricate drones, build field structures, and survive hostile machines while the drive stabilises. Then you recall the crew and transit to the next Earth.

## Play

Open `index.html` in a browser. It runs straight from disk with no build step and no server.

For a single file you can share or play offline, run `npm run build` and open `dist/ad-ezp.html`.

Choose **New Game → Save Slot → Launch expedition**. The same seed always generates the same terrain.

| Input | Desktop | Touch |
|---|---|---|
| Select | Click a unit, drag a box, shift-click to add | Tap a unit; hold on empty ground, then drag, to box-select |
| Move | Right-click terrain | Tap terrain |

Saves go to three browser slots (autosave every 60 s and on each transit). You can also export and import them as JSON from the Expedition log. Saves from v0.5 load and are migrated automatically. Before an older save is upgraded, its original is kept in browser storage as a backup. A save that can't be loaded is reported instead of loaded, and your current game is left as it was.

## Develop

```
npm test               # static checks + headless simulation and save-format tests (no dependencies)
npm run test:browser   # real-browser tests: desktop, touch, bundled build, 2,000-unit stress
npm run build          # dist/ad-ezp.html, one self-contained file
npm run save:snapshot  # after bumping GW.SAVE_SCHEMA: record the new save shape and fixture
npm run sprites        # regenerate the pixel-art test set in art/pixel-test (sprites:preview also renders previews)
```

**Pixel-art sprites (test branch).** Utility Spiders, drones, Vance, the Repair Station and the grass terrain are drawn with top-down pixel art from [art/pixel-test](art/pixel-test/README.md). Add `?art=classic` to the URL, or use **DEBUG → Pixel-art sprites**, to switch back to the original art. See "Pixel art" in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). New art follows [art/PIXEL_ART_RULES.md](art/PIXEL_ART_RULES.md).

Changing what a save contains? Follow the checklist in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#changing-the-save-format). The tests fail if the save format changes without a schema bump and migration.

The browser tests need Playwright and Chromium (`npm install --no-save playwright && npx playwright install chromium`). A global install also works. `PLAYWRIGHT_MODULE` and `CHROMIUM_PATH` can point at existing installations. When Playwright is missing, the tests are skipped. CI (`.github/workflows/test.yml`) runs everything and uploads the build and screenshots.

The code is split into a DOM-free **simulation** (`src/core`, `src/data`, `src/world`, `src/sim`) and a **presentation** layer (`src/render`, `src/ui`). The simulation runs headless in Node, which is how the tests drive whole expeditions in milliseconds.

**[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)** explains the structure and how to add units, items, structures, behaviours, resources and systems. Most new content is a data definition only.

**[docs/DESIGN.md](docs/DESIGN.md)** holds the game design: modes, threat, the curated Earths and the story (with spoilers). **[docs/ROADMAP.md](docs/ROADMAP.md)** is the to-do list, including what Alpha needs.

## What changed in v0.7

- **Trails, natural cliffs, spray and mist, and stepping stones (Genesis maps).**
  - **Trails** are drawn along contours like the water: packed dirt with pebbles and a worn middle, fraying into grass at the edges, so a stair-stepped trail becomes a smooth band.
  - **Cliff faces** are natural fractured rock (slabs of different sizes and tones, broken cracks, water stains, moss, grass hanging over the lip, a ragged foot and scree below). Grassy slopes and carved steps now run in the same band as the rock, as a grassy ramp or a flight of steps, instead of flat squares.
  - **Spray and mist** roll off the foot of every waterfall, with a low haze over the plunge pool.
  - **Stepping stones (new terrain, `stepping_stones`):** a few narrow places on the rivers and the creek have a line of rocks across, with level, walkable banks on both sides. Units can cross them, slowly (speed ×0.7). Water foams around each rock, trails a wake downstream and ripples away in chevrons, with a little spray and mist. Also in the Map Editor's terrain list.
  - **Bushes, flowers and other features** are new pixel art at natural positions instead of one flat drawing per tile: leafy bushes in three sizes (some with red berries), patches of wildflowers whose colour changes from meadow to meadow, boulders in three sizes (mossy ones by damp ground, often with a small stone beside), dense reed clumps with cattails, mushroom clusters, and ferns on the forest floor. They are drawn and destroyed like the trees: blasts and a Salvage Crawler clear bushes, flowers, reeds, mushrooms and ferns (bushes give a little wood); boulders can't be destroyed. Loose ground detail (pebbles, leaves, tracks) is scattered off the grid.
  - **Stepping-stone crossings** are rows of small rocks in six sizes (mostly pebble-sized, round a few bigger stones): four or five abreast mid-stream, widening to eight or nine at the banks, where a worn dirt path meets them. No stones lie on the land.
  - **Everything else in the landscape is upgraded** to pixel art at natural positions: tall grass as dense clumps (no more square tiles), thickets, large boulders (a fourth size), termite mounds, steam vents (with rising steam and the odd burst), crystals, mineral outcrops, alien plants, log piles, sawhorses, burrows, rubble, and small grass tufts, weeds, pebbles, fallen leaves, twigs, bones and puddles in place of the old ground marks. Barren ground, sodden fen ground and grassy slopes blend along contours instead of in squares, and bog is dark peaty water with lily pads.
  - **Crossing rocks** each have their own irregular shape, lean and tone; the rows wander and vary in width, with gaps here and there, so no two crossings look alike.
  - **Houses** in the villages have real roofs: hipped slate or clay-tile roofs laid in courses, lit on the north and west slopes, with ridge and hip caps, moss on the shaded side, stone chimneys, door steps and lamps. Log huts in the logging camps have plank roofs. **Ruins** show low stone or log walls with tumbled gaps and rubble, casting shadows over rotted plank floors.
  - **Bridges** are plank decks running across the water, one direction for the whole bridge, with log rails along the open sides, posts at the ends and a shadow on the water below.
  - **Cave mouths** are dark arches in the cliff face, with a rocky rim, teeth of rock hanging from the roof and scree spilling out.
  - **Swamps** have peaty pools with muddy lips and lily pads, mossy hummocks, tufts of sedge and dark sodden ground; bog water has rafts of duckweed and notched lily pads.
  - **Crossings** are grey stone only, set square across straight stretches of river, with bars of wet gravel running from the rocks up into the banks.
  - **Bridges run square:** each bridge is a straight deck two tiles wide running north–south or east–west, the river runs square under it and bends gently back into its own course over the next few tiles either side (no squared-off pools), and the trail meets each end head on (any trail that used the old bridge is paved through to the new one; where that isn't possible the bridge is left as it was).
  - **Villages look lived in.** Buildings are never against a cliff, in the water or across a change of level (one that would be is moved to open, level ground nearby). Every door has a path to the road. Each village has a barn with a red plank roof and cupola, a fenced paddock with hay bales, a haystack and a cart, a well on the green with benches and a signpost, lamp posts along the lanes, barrels, crates and rain barrels against the walls, and flower beds by some doors. Most of the long grass between the houses is cut. The new props (lamp, sign, bench, barrel, crate, well, fence, hay, cart) are drawn and destroyed like the rest of the landscaping.
  - **Banks and hummocks:** a one-level bank is either all grassy slope or all cliff (no more grass-covered rock faces or rock strips in a slope); slopes are drawn as soft grassy banks without a cliff's shadow. Fen hummocks are raised mounds, lit on one side and casting a shadow.
  - **Night and day.** Genesis maps have a day of 10 minutes of game time, starting in the morning. At night the land goes dark blue, and the lamp posts in the villages glow warm and flicker a little. The ship, Vance and the other friendly units carry their own lights. This is drawing only and has no effect on play.
  - **Caves have insides.** Behind every cave mouth is a cavern cut into the rock, a level below the ground round it and walled in by rock. It is either small, or medium with a side chamber, and you enter through the mouth along a short passage. Caves are dark even by day, lit by glowing crystals and fungi. Each cave has a cache at its deepest point. An ordinary Cave Cache holds Cave Crystals, Salvaged Alloy and sometimes a Miner's Helmet. A Rare Cave Cache holds a Prototype Visor or an Expedition Pack. Some caves hold a **Hostile Nest**, which sleeps until a friendly unit comes within 9 tiles. It then makes Hostile Autonomous Machines that guard it and attack anything within 6 tiles, and it keeps making them until it is destroyed. Some caves hold a **Black Box Recorder** with one of ten recordings from other Earths (the lost archives). Opening it plays the recording in the Expedition log. New terrain: `cave_floor` (id 40), also in the Map Editor.
  - **Clock.** On maps with day and night, a clock by the Menu button shows the time and the day of the expedition. A sun or moon on a small dial rises and sets across it.
  - **Ramps and ledges.** Grassy ramps and carved steps blend into the rock beside them along a ragged edge instead of a straight cut at the tile edge, and no line is drawn across them. Trails run on over carved steps. Low edges whose face isn't visible from above are drawn as a soft ledge (a lit brow above, a shadow fading below) instead of a thin line.
  - **Cliffs and ramps are told apart on every side.** Where the ground drops to the east, west or north (sides whose face can't be seen from above), a cliff now shows a strip of brown rock face along its top edge, lit where it faces west and dark where it faces east, with grass over the lip. A ramp shows a grassy bank with hachures (short strokes running down the slope), light when it faces west and shaded when it faces east. South-facing ramps get the same strokes. No thin line is drawn along either.
  - **Ramps are cuts in the cliffs, as in Factorio.** Cliffs run unbroken along one-level edges, and ramps are gaps three tiles wide cut through them, about every 16 tiles along an edge that used to be slope (at least one per edge, and wherever a trail crosses). A cut never leaves ground that could be walked to before out of reach: where it would, a ramp is opened through the cliff. Ramps are drawn as plain grass rolling down with a soft shade, and no edge line or stripes.
  - **More trees.** Open grass away from trails, water, villages, camps and the landing site now grows its own woods (large irregular stands on about a third of it) and scattered copses, so no part of the map is nearly bare. About 40% more trees in all.
  - **Ground textures.** A new texture layer (`src/render/ground.js`) breaks up the ground by what grows there, blending between tiles: meadow grass with lighter and darker patches, clover and the odd tiny flower; forest undergrowth that is dark and mossy, with drifts of fallen leaves, needles and twigs; rough, darker brush with seed heads; dense flecks of colour in wildflower meadows; and worn earth fraying round the trails.
  - **Real-looking rocks.** Boulders, rubble, pebbles and outcrops are irregular stones, not circles: 7 to 10 uneven corners, stretched and turned, broken into facets that catch the light on the upper left, with cracks, lichen and (on mossy ones) patches of moss. Boulders come in granite, slate and sandstone, often with a smaller stone or two beside them, in eight variants.
  - **Hover info.** Hovering the mouse over anything shows what it is in a small panel at the bottom left, above the selection panel: units and structures (HP, damage, description), containers, resources, trees and landscape props (toughness, wood), and the ground (water, cliff, ramp, grass, flowers…) with what it means for movement and its height. Press **~** to turn it off or on; the choice is remembered.
  - **Sharper up close (engine).** Terrain chunks are now painted at the screen's own resolution, 1, 2, 3 or 4 canvas pixels per world pixel (high-DPI screens included), instead of at most 2 and then stretched. Water, cliffs, ramps, ground texture, roofs and caves are drawn pixel by pixel, so they gain real detail. From 3× up, chunks are half as many tiles across, so they cost the same to paint. The cache is sized by memory (`CHUNK_CACHE_MAX` 128 full-size chunks, about 300 MB) and steps the resolution down when a view wouldn't fit. Chunks are painted a band of tile rows at a time within each frame's budget, so even a 4× chunk never stalls a frame. House and cave art is drawn ahead in spare time, nearest the camera first. You can zoom in to 4× (was 2.2×). With pixel art on, once you stop zooming the camera eases to the nearest zoom at which every art pixel covers a whole number of screen pixels, so pixel art stays crisp and even instead of shimmering.
  - **Higher-resolution art.** Trees, stumps, fallen trees and every landscaping and village prop are now drawn at 4 art pixels per world pixel (192 per tile, was 96), regenerated from the same drawings (`tools/genesis-trees.mjs`, `k: 4` in the data). Crowns are built from lit and shaded leaf clumps with fine foliage broken over them, so they hold their texture up close. Grass up close (3× and in) is a new seamless 4 px per world px texture of individual blades, clover and tiny flowers, under the ground-texture layer. The tree renderer reads the art scale from the data and keeps mipmaps down to an eighth. The art data grows by only about 0.5 MB.
  - **Terrain loads from the centre out.** Terrain chunks missing from the view are painted nearest the middle of the screen first, for a few milliseconds each frame, instead of two a frame from the top-left corner. Chunks on screen are never dropped from the cache. Until a chunk is painted, the best copy at hand stands in (another resolution, or the other tree layer). Once the view is complete, the ring of chunks around it is painted ahead for scrolling. Zoomed out, chunks are painted at half resolution without sub-pixel ground detail, 2–4× faster. The detail thresholds have some give, so zooming back and forth across one no longer repaints the whole view.
  - **Save schema 10.** Cave caches hold stacks of items (`count` instead of durability), so saves move to schema 10. Nothing changes in the saves: the migration from 9 only sets the new number.
  - Saves are unchanged (still schema 9): terrain edits can use the new terrain id 39, and the landscaping is part of the tree list that the save already records damage for.
- **Water, shores, cliffs and waterfalls along contours (Genesis maps).** Water and ground height are now drawn along smooth lines between tile centres instead of tile by tile, so an edge that steps one tile becomes a 45° diagonal, corners are cut at an angle, and shorelines and cliff rims wobble a little like real ones.
  - **Water** shades by depth: pale shallows along the edge, open water, and dark where a channel runs deep (no more deep-water squares), with drifting ripples, a broken foam line at the edge and a wet mud bank and damp grass on the shore. Glints of sunlight wink on open water up close.
  - **Cliffs** hang their rock face one tile down from the rim, over the cliff tiles that block, and diagonal rims give slanted faces. Faces toward the viewer (south) show stone courses, cracks, moss and a dark foot with a shadow on the ground; north, east and west drops show a lit lip and a shadow line. Caves open in the face, and grassy slopes and carved steps stay faceless.
  - **Waterfalls** are a curtain of falling water where a river crosses a rim, animated up close: streaks sliding down, foam boiling at the foot and rings of foam spreading across the plunge pool; falls running sideways stream along the flow.
  - Reeds, boulders, mushrooms and the other small features stand on grass art instead of a flat square of colour.
  - Presentation only: movement still follows the tiles, and saves are unchanged. Woodlands maps look as before.
- **Wood, falling trees, dust and scorch marks (Genesis maps).**
  - **Wood (new resource):** whatever a Salvage Crawler saws down goes into its hold as wood: 8, 20 or 40 from a small, medium or large tree (maples 20% more, dead snags half), 4–8 from a stump and 25–40 from a fallen tree. It then hauls the wood to the nearest drop-off (the ship, unless another is closer) and stops. With a full hold it unloads first, then comes back to saw. Blasts give no wood. Wood shows in the top bar once you have some, and up to 200 crosses to the next Earth.
  - **Falling trees:** a felled tree falls away from the saw or blast, faster as it goes, with a short trunk coming into view, and bursts into dust and is gone the moment it hits the ground (1.3 s). A Crawler gets a felled tree's wood at that moment. A Crawler throws up sawdust while it cuts, and cleared stumps and fallen trees burst into splinters.
  - **Blasts** flash, throw up smoke and dust, and leave a scorch mark on the ground, on any map. Scorch marks last for the session and aren't saved.
  - **Treetops over units:** a tree's crown is now drawn over the ground units under it, slightly see-through, so a Crawler working in the woods is under the canopy rather than on top of it. Drones fly above the trees.
  - Saves are unchanged (still schema 9): wood is a new resource in the existing stockpile and cargo.
- **Trees can be destroyed (Genesis maps).** Trees, stumps and fallen trees now take damage.
  - **Explosions:** shells and missiles from the Heavy Turret and Missile Battery explode among the trees wherever they land, hit or miss. A tree that is blown down leaves a snapped stump, and blasts clear stumps and fallen trees away.
  - **Salvage Crawler:** select one (or several) and right-click or tap a tree, stump or fallen tree. It walks up and saws it down with its arms; a tree leaves a sawn stump, and sending it again clears the stump.
  - **Toughness:** small, medium and large trees take 60, 160 and 320 damage (maples 20% more, dead snags 40% less), stumps 90–150 and fallen trees 200–320. A Crawler saws a large tree down in about 9 seconds.
  - Whatever a trunk or fallen tree was blocking opens up for movement and building. **Map Editor → Blast** sets off an explosion where you tap, for testing.
- **Save format: schema 9.** Saves record the damage done to trees (`trees`: index, state and damage for each tree touched); the trees themselves are still rebuilt from the seed, and the tiles they free are saved as terrain edits. `migrate_8_to_9` gives older saves an empty list, with every tree standing.
- **Genesis v0.1 (new map type, `genesis`): free-standing trees.** The landscaping test bed. For now it is the Woodlands landscape for the seed with every forest replanted. Trees are no longer one per tile at the tile's centre: each has its own trunk position and grows in natural clusters. There are thick stands where the crowns close over, thin open woodland, glades, saplings at the forest edge and big lone trees out in the meadows. Five species in three sizes, placed by habitat: spruce (high ground and the fen), jack pine, paper birch (by water and in birch groves), sugar maple (broad mixed woods) and dead snags (mostly in the fen). Dead wood lies among them in place of the old tile-sized stumps and fallen trees: sawn stumps along the trails and in the logging camps, snapped stumps in open woodland, and fallen trees with their root plates torn up, lying at any of 16 angles, often a few together from the same storm, with the living trees growing around them. Medium and large trees block the tile their trunk stands on, and fallen trees the tiles along their trunk; stumps, small trees and the forest floor between the trunks slow units but let them through. Up close (zoom 0.7 and in) trees rustle and lean in the wind by species: conifers stiffly, birches flutter most, snags only sway. Further out they are drawn into the terrain at rest. Trees overlap in depth order (small under big, north under south) over one merged shadow, and taller trees throw longer shadows. Choose **Map → Genesis v0.1** in New Game, or load it from Map Editor → Maps. With pixel art off, trees are plain round crowns. The art is stored run-length encoded, so all of it adds only 0.3 MB. Trees are rebuilt from the seed like the rest of the terrain. Saves are unchanged (still schema 8); `genesis` is a new accepted value for `map`.
- **Laser Turret (new structure).** A heavy laser rifle on a diamond pad: 180 metal and 6 electronics, 700 HP, draws 6 power. With a ground target within 380 it charges for 2.5 s, the six coils down the rifle lighting one by one, then fires a 60-damage cyan beam from the rifle's emitter; it loses the charge when no target is left. It traverses at half a turn a second and holds a charged shot until the rifle is on target, so the beam always leaves along the barrel. Saves are unchanged: a turret's charge, like its cooldown, restarts when a game loads.
- **Build walls in rows.** With a wall picked in the build menu, press on a tile and drag: the row runs from there the way you drag, east–west or north–south, up to 24 tiles, with a preview of how many and what it costs. The Spider builds them one after another. Blocked tiles are skipped, and the row stops where the resources run out; a new order for the Spider cancels the rest and refunds it. A tap still builds one section. Saves are unchanged: each tile is its own construction site, as before.
- **New walls that join up, and gates in three lengths.** Three walls: the new **Wood Wall** (a cheap palisade of sharpened logs with stakes angled out, 350 HP, 25 metal), the **Metal Wall** (the old Defensive Wall, renamed and redrawn) and the **Reinforced Metal Wall** (the old Reinforced Wall, renamed and redrawn, crenellated). With pixel art on, wall tiles built side by side join into one continuous wall, of any kind, and join the ends of gates; tiles that only touch at a corner don't. The **Gate** comes 1×2, 1×3 and 1×4 long (the longer ones cost more and are tougher); in the build menu **Rotate** (or R) turns any of them to fit a north–south wall. Gates show open and shut. Old saves keep their walls and gates (their keys are unchanged). Saves are unchanged.
- **Sentry Turret pixel art, with a head that turns.** With pixel art on, the Sentry Turret is drawn from a sprite-lab model: a hazard-banded pad and slewing ring, and a gun head that turns to track the enemy it is shooting at, in 16 directions, easing round rather than snapping. After each round it shows a muzzle flash and recoil. It has every construction state, a damaged look (bent barrel, rust, a blinking red fault lamp) and rubble. Structures can now have a turning head layer like this one. Saves are unchanged.
- **Salvage Crawler (new unit).** A tracked crew unit that saws wrecks apart with two telescoping arms and hauls the scrap to the ship. Fabricate it at the ship or a Fabricator for 220 metal (16 s). It only works Scavenging Mines, never Metal Mines or Resource Extractors, and cuts 1.5× faster than a Utility Spider into a 400 hopper (a Spider carries 250). It is tougher (700 HP) and slower than a Spider and can't build. With pixel art on, its arms take turns reaching into the cut with sparks instead of a laser, and its hopper shows how full it is: empty, a quarter, half or full. Saves are unchanged.
- **Sprite lab and `/sprite`.** New sprites can be tried out before they go in the game. A sprite is described as a 3D model in code (`art/sprite-lab/specs/`), and `npm run sprite -- <spec>` renders it straight top-down at 96 × 96 per tile. It checks the result against the pixel-art rules (frame, inscribed circle, palette, team colour, animation names, silhouette against the Utility Spider) and writes a test page: the fit report, all eight facings, animations, the sprite beside today's Spiders and a crowd at ⅓ zoom. The rules now include a lore and style check for crew, hostile, local, nature and anomaly designs. In Claude Code, `/sprite <short description>` goes from an idea to a published test page. Nothing in play changes.
- **Sharper terrain and trees (96 × 96 per tile).** With pixel art on, the dust plain, all Woodlands ground (grass, tall grass, water, deep water, shorelines, cliffs) and the oak, pine and birch trees are drawn at 96 × 96 art px per tile, like the units and structures: the same designs and size on screen, with finer grain, one-pixel seams, blades, cracks and ripples, and smoother tree crowns. Zoomed in, close terrain shows every pixel; zoomed out, the tiles are averaged so they don't shimmer. The game stays straight top-down. Saves are unchanged.
- **Sharper unit and structure art.** Utility Spiders, drones, Vance and the Repair Station are drawn at twice the pixel resolution (2 art px per world px; a Spider is 98 × 98 art px). They keep their designs and their size on screen, with smoother curves and diagonals and finer outlines and edge shading. Terrain and trees are unchanged. Saves are unchanged.
- **Woodlands map** (new map type, `woodlands`). A generated 512 × 512 woodland over five height levels. Cliffs mark every step between levels and block movement; grassy slopes and carved steps cross them. Rivers only run downhill, so there is a waterfall wherever one drops a level. It also has a lake and creek, a sunken swamp, villages of standing and ruined buildings, logging camps with a log hut and sawhorse, 2–4 caves (rarely 7–8), boulders, thickets, mushrooms, alien plants and crystals, a geothermal field, and scattered ground detail such as pebbles, leaves and tracks. The ship lands on a flat clearing 48 tiles across. Height, cliff faces (one tile tall) and ground detail are drawn only; the game map stays flat.
- **Choose where the ship crash-lands.** New Game now has a **Map** choice (test map or Woodlands) and a **Landing site**: centre of the map, random, or a tile you type in (64–447). In a game, Map Editor → Maps → **Preview** has **Choose landing site**: tap the full map and the preview is generated again around that spot, then **Start a new expedition here** (replaces the game in this slot) or **Load terrain into this game** (keeps your game; the clearing goes at that spot). Woodlands keeps the landing clearing off water: a site within 36 tiles of a river, lake or creek moves to the nearest dry ground, and the game says where. Rivers, the lake and the creek never move for it; villages, zones, streams and trails are placed around it. A landing at the centre generates exactly as before.
- **Save format: schema 8.** Saves record the landing site (`landing`, in tiles), because the map generator builds the landing clearing there. `migrate_7_to_8` gives older saves the centre of their world, which is where every earlier ship landed.
- **Debug hover info.** While the Debug panel is open, hovering the mouse over a structure, unit, container, resource node, signal or terrain feature shows an info box: for terrain, its name, tile, whether it blocks movement, its height level, ground detail, the nearest named place and, for trees, their kind and the wind.
- **Sharper units when zoomed out (pixel art).** Units no longer blur below 1:1. On the GPU path the sprite texture's smaller copies are point-sampled rather than averaged, and the nearest pixel of the nearest copy is used; the Canvas 2D fallback's half- and quarter-size copies are no longer smoothed. With pixel art on, ordinary units now turn into team squares only below zoom 0.30 (was 0.45). Very far out a unit can lose a pixel here and there; that is the trade-off for staying sharp. Classic art keeps its smooth scaling.
- **Detailed terrain further out.** Terrain now stays detailed down to zoom 0.20 (was 0.30), 1.5× further out, using lower-resolution chunks (a third of full size, trees drawn in at rest) between 0.30 and 0.20, and on large screens where the view holds more than 64 full chunks. Below 0.20 the map image shows as before.
- **Woodlands pixel art (pilot).** With pixel art on, Woodlands maps draw grass, tall grass, water and deep water as pixel-art tiles (8 weighted variants each), shorelines with a muddy bank and foam, one-tile cliffs with a piece for each side that drops (south faces in detailed stonework: lit stone blocks, cracks, moss, hanging grass and loose stones at the foot, in 4 versions; ragged rock rims on the other sides), and trees as outlined canopy props with an engine shadow. Trees come in three kinds that grow in groves: round oaks, spiky dark pines (mostly on high ground) and light birches (mostly by water). **Wind:** trees have two motions, leaves rustling and the crown leaning downwind (east), and the weather sets both. ## What changed in v0.6

- **Restructured.** The 245 KB single-file build and its monkey-patching extension scripts are replaced by 41 focused modules. `index.html` is now the real source entry point. The old `build.py` depended on a source folder missing from the repository, and the old test scripts used hard-coded machine paths; both are removed.
- **Scales to thousands of units.** Measured headless: 2,000 units in active combat take about 11 ms per 33 ms tick (about 20 ms before the final optimisations), and 3,000 idle units about 12 ms. In the browser, 2,000 units render at about 30 fps under headless software rendering.
  - **Grid:** tile passability is an O(1) lookup, where the old code scanned every building on each check.
  - **Spatial hashes:** per-team hashes, so target searches only look at opposing teams.
  - **Pathfinding:** A* reuses preallocated arrays instead of allocating 262,144-element arrays per search. Unreachable goals are rejected using connected regions. Blocked targets fall back to the nearest reachable tile. Group moves share one flow field. AI route requests go through a time-budgeted queue.
- **Data-driven content.** Units choose behaviour by capability, not by type name. Structures get their function from a behaviour list. Fabrication recipes, resources, climates and expedition balance are all data.
- **Economy.** Every resource change goes through one API with a rolling income/expense ledger, shown in the Game menu and the Expedition log.
- **Fixes:**
  - A construction site whose builder died was never cleared, so departure stayed blocked for the rest of the game. It is now refunded.
  - A Spider-built chest used to become an invisible solid block. It is now a container.
  - A construction approach tile diagonal to a 2×2 structure could leave the builder retrying forever.
  - Terrain edits (landing zone, testing zone) are now saved, so the ground no longer reverts on load.
  - The testing-zone Sensor Station no longer collects a generated signal for free.
  - Removing a backpack can no longer strand items beyond your capacity.
  - Minimap colours now match the terrain.
- **GPU unit rendering.** Units are drawn by WebGL2: each unit's art (including Vance's hover and the Spider's walk frames) is painted once into a sprite atlas, and every visible unit is then drawn in a single instanced call, with health bars in a second. Map, structures and overlays stay on Canvas 2D layers. Drawing 3,000 units went from 9–50 ms of CPU per frame to about 1.5 ms. Browsers without hardware-accelerated WebGL2 automatically use a Canvas 2D fallback that stamps the same sprites. `?renderer=2d` or `?renderer=gpu` forces either one, and F3 shows which is active.
- **Swarm AI for enemies.** Hostile Autonomous Machines no longer each run their own route search. They follow one shared flow field toward Vance, built in small fixed slices across ticks and weighted to spread crowds across gaps. When anything friendly comes within 10 tiles (crew, the ship or player structures), they break off and attack it, and resume the march when it's gone. Enemies boxed in near the front hold position instead of shoving. In a real browser, 5,000 swarming enemies take about 4.5 ms per tick (11 ms before), and zoomed-out views stay at 45–60 fps by drawing distant units as batched markers.
- **Deterministic simulation.** Background work (flow fields, route searches) is budgeted by amount of work, not time, so a given game plays out identically on any machine. A test checks this. The static check also rejects wall-clock reads and `Math.random` in the simulation. Armour wear, the last random choice, is now seeded.
- **Save discipline.** The save format is fingerprinted per schema version. There is one fixture save per version, migrations are a chain of named steps, and saves must round-trip exactly. Older browser saves are backed up before they are upgraded, and a save that fails to load leaves the current game running.
- **Expedition log** no longer has Explore with Vance, Assign mining or Survey drone.
- **Two ways to get metal.** *Scavenging Mines* are loose salvage a Spider collects itself, fast (20/s), until they run out. *Metal Mines* are 1×1 deposits with a near-endless reserve. Nothing happens until you build a 3×3 **Mine Building** centred over one. It then extracts slowly (2/s) into a 300-unit stockpile, and Spiders haul that stockpile to the ship. Each Earth has two Metal Mines near the ship, and the testing zone has one with a Mine Building already on it.
- **Follow** replaces "Follow Vance". Any friendly unit, Vance included, can follow any other friendly unit you tap. A dashed line shows who it is following.
- **Utility Spider storage** is 25 slots, shown in the selection panel. Older saves are upgraded when loaded.
- **Hostile Fabricator** (test tool): a spawner structure that produces Hostile Autonomous Machines at 1–1,000 per second, up to 20,000 in total. Spawned units hold position or hunt the crew. Its window shows live unit counts, on-screen count, fps and frame times. It is hidden from the Spider's build menu.
- **Now working:** the Repair Station heals nearby units, and the Sensor Station studies signals in range (its description already claimed this).
- **Removed dead features:** the XP/skill tree and coin currency. The v0.5 expedition layer had disabled both, and they no longer appear in the interface.

Not tested: physical mobile devices, Safari and Firefox.
